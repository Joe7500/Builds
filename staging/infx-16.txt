Changelog for @ProjectInfinityX v3.11 Release:

- Complete Android 16 ROM Screenshots  (https://t.me/ProjectInfinityX/1697?single)

NOTE: As always the author’s name is listed at the end of line for each change (wherever applicable) to give proper credit for their respective work used in our project. A big thanks to all the wonderful authors!
If you believe you are the original author of any change mentioned here, or if you notice any incorrect credit mention, please feel free to DM @tejas101k for re-verification and correction.

- Merged June 2026 security patch
- Add recents panel styles (OOS, iOS, Scale etc.) (author: kamikaonashi, elpaablo, zylhdrXP)
- Switch to inbuilt trickystore implementation for playintegrityfix (https://t.me/ProjectInfinityX/1881) (fixes google wallet and gpay nfc contactless payments) (author: rmp22, Dakkshesh, reveny, joeyhuab, neobuddy89)
- Add app sandbox, private file vault and custom password app lock feature replacing traditional applock and hideapplist features (author: rmp22, Saikrishna1504)
- Bring back statusbar swipe brightness control feature and add support for lockscreen statusbar too (author: neobuddy89, ergdevops)
- Add peek AOD feature to briefly show ambient display for a few seconds after screen off (author: shutter-cat)
- Fixed no transition to homescreen when unlocked with fingerprint in AOD
- Fix small (ill-formed) wifi/network icons in theme styles (author: rmp22)
- Make app icon shapes work in appdrawer even when themed icons disabled (author: nnn950711)
- Fix extremely low signal strength display for 5g network connection (author: rajdeep-3305)
- Increase connectivity coverage for LTE+
- Bluetooth connectivity improvements
- Add new lockscreen clockstyles (author: Ghosuto)
- Improve new lockscreen clockstyles layouts and preview (author: neobuddy89)
- Fix full screen apps feature on tablets
- Allow using split shade qs feature (separate qs/notification panel) on all qs panel styles (author: TwistedVision518 for certain improvements)
- Improve app opening animations like Stock roms (author: rmp22)
- Add recents panel app hold gestures feature to open in freeform/split screen (author: zylhdrXP)
- Fix default google sans flex font characteristics (rounded edges and correct variable weights) (author: joeyhuab)
- Apply drag lock to dynamic bar expanded media panel seekbar also use waveform seekbar style with refinements (author: Ghosuto, neobuddy89)
- Fix some music apps shuffle button icon in dynamic bar expanded media panel
- Improve clock styles and AOD view
- Improvements for QS Panel smoothness under heavy load
- Enable power button assistant invocation effect (author: ralph950412)
- Add custom carrier text and location customization (author: Claymore1297, neobuddy89)
- Add partial screenshot as custom action for gestures (author: luk1337)
- Re-design freeform window to pill based (tap pill to to back, swipe bottom to top to close, top to bottom to open app) (author: zylhdrXP)
- Add feature to auto hide sidebar pill when gamespace active (author: kenway214)
- Remove some useless bloated fonts
- Fixed ota updates that got broke for some A only devices in first 3.10 release 
- Fixed awkward search icon placement in app drawer searchbar when homescreen searchbar disabeld
- Preserve locked rotation during screen state changes (author: ArKT-7)
- Fixed no haptics on extended volume panel style when changing volume from physical keys, also make expanded volume panel style follow volume panel timeout settings
- Bring back system animation styles from v3.5, along with the fixed-style MediaTek transition animations as a selectable option.
- Improve UDFPS unlocking speed and overall system speed when device unlocked
